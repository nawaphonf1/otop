# OTOP นวัตวิถี · บ้านผารังหมี (หน้าหลัก)

หน้าหลักของเว็บไซต์ประชาสัมพันธ์สินค้า OTOP ชุมชนบ้านผารังหมี อ.เนินมะปราง จ.พิษณุโลก
แปลงจากดีไซน์ Figma มาเป็น **Vue 3 + Vite**

## รันโปรเจกต์

```bash
npm install
npm run dev      # เปิด dev server (http://localhost:5173)
npm run build    # build โปรดักชันไปที่ dist/
npm run preview  # พรีวิว build
```

## โครงสร้าง

```
src/
  App.vue              ประกอบทุก section
  main.js
  style.css            design tokens (สี/ฟอนต์) + base + .app-shell (กรอบมือถือ)
  assets/              รูปจาก Figma (ฉากภาพประกอบ + รูปสินค้า + โลโก้)
  components/
    TheNav.vue         แถบเมนูบน (sticky) + เมนู hamburger บนมือถือ
    SectionHero.vue        1. จุดประสงค์เว็บ (ฉากภาพ + ปุ่ม "สินค้า OTOP")
    SectionHistory.vue     2. ความเป็นมา (ฉากภาพ + ลิงก์ "อ่านเพิ่มเติม")
    SectionLifestyle.vue   3. วิถีชุมชน (ฉากภาพ)
    SectionProducts.vue    4. สินค้า OTOP — แท็บ + การ์ดสินค้า (โค้ดจริง)
    SectionMap.vue         5. แผนที่กลุ่มผู้ผลิต (ฉากภาพ)
    SectionAllProducts.vue 6. ผลิตภัณฑ์อื่น ๆ + ปุ่มดูสินค้าทั้งหมด (โค้ดจริง)
    TheFooter.vue          7. แถบติดต่อ / footer (โค้ดจริง)
```

## หมายเหตุเรื่องแนวทางแปลง (อ่านก่อนแก้ต่อ)

ดีไซน์เป็น landing page แบบภาพประกอบเยอะมาก (เนินเขา หมี หมู่บ้าน เวกเตอร์จำนวนมาก)
จึงใช้แนวทาง **ไฮบริด** เพื่อให้ได้ภาพตรงต้นฉบับและโค้ดที่ใช้งานจริง:

- **ส่วนเล่าเรื่อง (hero / ความเป็นมา / วิถีชุมชน / แผนที่ผู้ผลิต)** → ใช้รูป PNG ที่ export
  จาก Figma โดยตรง (`assets/plate-*.png`, ความละเอียด 2x) เพราะเป็นงานภาพประกอบล้วน
  ข้อความในส่วนนี้ฝังอยู่ในรูป
- **ส่วนที่ต้องโต้ตอบ (nav, การ์ดสินค้า + แท็บ, ผลิตภัณฑ์อื่น ๆ, footer)** → เขียนใหม่เป็น
  HTML/CSS/Vue จริง แก้ไข/เพิ่มข้อมูล/ทำ responsive ได้เต็มที่

ถ้าต้องการให้ข้อความในส่วนเล่าเรื่องเป็น HTML จริง (แก้/แปลภาษาได้) สามารถแยกภาพประกอบ
ออกจากข้อความแล้ววางข้อความเป็น element ทับบนภาพได้ภายหลัง

## ข้อมูลที่เติมเพิ่ม (ให้หน้า "สมบูรณ์ขึ้น")

- Nav แบบ sticky + เมนู hamburger + smooth-scroll ไปแต่ละ section
- แท็บ "สินค้ายอดนิยม / สินค้าทั้งหมด" ที่กรองการ์ดได้จริง + ปุ่มหัวใจ (favorite)
- section "ผลิตภัณฑ์อื่น ๆ" + ปุ่ม "ดูสินค้าทั้งหมด"
- footer เขียนใหม่ครบ (เมนู / ที่อยู่ / เบอร์โทร กดโทรได้ / ลิขสิทธิ์)
- responsive: จอกว้างจะแสดงเมนูแนวนอนและ footer แบบ 3 คอลัมน์

ราคา/รายละเอียดสินค้าบางส่วนเป็นตัวอย่าง (ในดีไซน์เห็นเฉพาะบางค่า) แก้ได้ที่
`SectionProducts.vue` และ `SectionAllProducts.vue`
